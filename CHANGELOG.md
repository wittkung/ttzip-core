# Changelog

All notable changes to `ttzip-core` are recorded here. The project follows
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

This repository is the open-source mirror of the TTZip core engine. It is
generated by a one-way export from the internal monorepo, so every entry below
describes a change that is already present in `main`.

## [0.1.0] — 2026-11-02

First tagged release of the standalone core engine. The archive formats,
codecs, CLI, Swift 6 SDK, and the C/C++/Python SDK guides are available today.

### Added

- Semantic indexing lifecycle with an isolated native executor, explicit
  runtime preparation, and explicit lifecycle ownership.
- Archive-scoped password support in the encrypted vault, including staged
  password controls, a forget lifecycle, and persistence of scoped passwords.
- Transactional archive creation with explicit cleanup reporting.
- Swift 6 SDK for the core engine, the `ttzip` POSIX CLI, and the
  `ttzip-bench` telemetry suite.
- SDK guides for C, C++, Python, Rust, Swift, Go, Node/TypeScript, Dart and
  Flutter, JVM/Kotlin, and .NET.
- GitHub Actions CI that runs the single-file line-count gate, the Rust
  workspace test suite, and the Swift package test suite on the standalone
  tree.

### Fixed

- Snappy rejects impossible raw output lengths before allocating.
- VFS snapshot bounds and borrowed views are validated before use.
- Archive password cache writes are fenced after a forget operation.
- Vault state stays consistent across failed writes and cancelled unlocks.
- Cancellation is arbitrated atomically for the async semaphore and the
  native compute dispatcher.
- `bytes_in_last_block` is set to 1 across all libarchive write paths.

### Notes

- The exported tree contains only the engine. The macOS client lives in its
  own repository, and the internal monorepo that produces this mirror is not
  published.
- Build outputs, benchmark corpora, and internal design records are stripped
  from the export, so this repository stays buildable from source with the
  Rust and Swift toolchains alone.
