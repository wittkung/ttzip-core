ttzip-cli 终端命令套件

10 大原子子命令、零依赖 ANSI/VT100 终端交互式 TUI 浏览器与 UNIX 管道流式流水线支持。

Homebrew 一键安装 macOS 14+ 
# 方式 1: 直接官方 Formula 安装
❯ brew install wittkung/ttzip/ttzip-cli

# 方式 2: 添加专属 Tap 源
❯ brew tap wittkung/ttzip
❯ brew install ttzip-cli
Shell 自动补全生成 Zsh / Bash / Fish 
# 1. 为 Zsh 生成自动补全脚本
❯ ttzip-cli completion zsh > ~/.zsh/completion/_ttzip-cli

# 2. 为 Fish 生成自动补全
❯ ttzip-cli completion fish > ~/.config/fish/completions/ttzip-cli.fish
explore TUI Interactive
启动零依赖 ANSI 交互式终端归档浏览器。支持使用 Vim 快捷键（j/k 移动、Enter 展开、Space 多选、e 提取、p 语法速览）。
ttzip-cli explore bundle.tar.zst
compress (c) Core Engine
高吞吐多线程压缩。支持 16 种格式、0~9 压缩级别、AES-256 硬件加密及标准输出 - 管道流式传输。
ttzip-cli compress ./src/ -f zst -l 3 -o out.tar.zst
extract (x) Stream-First
高速流式解压与密码探测。支持标准输入 - 零磁盘中转流式管道与 uchardet 自动编码修复。
curl -s url | ttzip-cli extract - -o ./data/
list (l) Direct Parsing
极速列出包内条目，支持 --json 机器可读格式与 --csv 导出，包含原始尺寸、压缩尺寸与 CRC 校验码。
ttzip-cli list archive.zip --json
tree (t) Visual Hierarchy
以 Unicode 树状拓扑渲染归档目录结构，支持指定 --depth 最大层级深度与只读文件过滤。
ttzip-cli tree archive.7z --depth 3
test (t) Integrity Check
免解压完整性验证。并发计算 CRC32 / CRC64 / SHA-256 校验码，校验数据块与 Central Directory。
ttzip-cli test archive.zip -v
bench (b) Hardware Monotonic
全矩阵硬件基准测试。执行真实内存与磁盘 I/O 压测，输出微秒级延时、CPU 核心利用率与 MB/s 吞吐。
ttzip-cli bench -f zst --matrix
inspect (i) Format Diagnostics
归档魔数与底层结构深度体检。诊断 Zip64 扩展头、Header 加密状态及 Zip-Slip 路径穿越安全隐患。
ttzip-cli inspect untrusted.zip
health (h) Engine Status
检查 CPU 特性支持状态（ARM64 PMULL、NEON、AES）、静态库链接版本及内存分页池健康度。
ttzip-cli health
man UNIX Standard
渲染 mdoc 规范的 UNIX 标准手册页，可与 man ttzip-cli 无缝集成。
ttzip-cli man
