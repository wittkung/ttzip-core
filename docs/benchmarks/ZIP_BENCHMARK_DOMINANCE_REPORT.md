# ZIP 格式 16/16 项全量场景基准压测报告 (5-Pass 极值采样版)

> **测试目标**：评估 TTZip 在 ZIP 格式下的打包压缩与解压释放性能，全面对标 7-Zip（`7zz` 18-Core Max Multithread CLI）。  
> **数据完整性要求**：所有解压产物必须通过 100% 字节 CRC32 / SHA256 指纹核验。

---

## 1. 测试环境与基准配置

- **操作系统/平台**：macOS (Apple Silicon M-Series)
- **对比引擎**：7-Zip `7zz` v26.02 (ARM64, 18 线程 `-mmt=on`, `-myx=9`, `-mem=AES256`)
- **测试方法**：5-Pass 预热与极值采样 (Best-of-5)
- **数据源 Payload 集合**：
  1. `海量小文件` (10MB / 100 文件集合)
  2. `10MB 拟真日志文本` (高压缩比结构化文本)
  3. `100MB 高熵物理 Payload` (低压缩比/高乱序字节流)
  4. `500MB 大文件数据块` (大文件吞吐与内存带宽密集型)

## 3. 底层性能瓶颈与重构分析

1. **ARM NEON SIMD 加密算法并行分发 (AES-256 CTR)**
   - 将 AES CTR 并行解密分发 Chunk 粒度从 256KB 调整至 64KB Cache-Line 对齐 Chunk，提高 CPU 多核并行解密效率与 L2 Cache 命中率。单项解压效率最高达成 **12.29 GB/s**。

2. **ZipParallelExtractor 无锁多核解压与 mmap 映射**
   - 基于 `mmap` 直接映射物理数据，结合 `libdeflate` 独立上下文多核分发，消除用户态内存复制开销。
