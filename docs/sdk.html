Universal C-ABI 2.0 In-Process Bridge

面向现代开发者的 8 大原生语言 SDK

100% 拒绝 `subprocess` 子进程管道调用。零成本抽象直接内存映射，为你的应用带来微秒级极速归档与虚拟 VFS 文件管理能力。

find_package(ttzip REQUIRED) 
// C++20 Modern RAII In-Process Archive Extraction
#include <ttzip.hpp>
#include <iostream>

int main() {
    // 100% 进程内纯 C-ABI 2.0 绑定，零子进程开销
    ttzip::ArchiveReader reader("backup.tar.zst");
    
    std::cout << "Format: " << reader.format_name() << "\n";
    std::cout << "Total Entries: " << reader.entry_count() << "\n";

    // 像虚拟文件系统一样遍历压缩包内文件
    for (const auto& entry : reader.entries()) {
        std::cout << " - " << entry.path() << " (" << entry.uncompressed_size() << " bytes)\n";
    }

    // 微秒级解压，支持实时流式进度回调
    reader.extract_all("./output_dir", [](const ttzip::Progress& p) {
        std::cout << "\rExtracting: " << p.percentage() << "%" << std::flush;
    });

    return 0;
}
Architecture

🚫 零子进程原则 (Zero-Subprocess)

所有语言 SDK 均直接与 `libttzip_core` 动态库进行原生内存级链接，绝不通过 `ProcessBuilder` 或 `system()` 调用命令行，杜绝进程挂死与安全注入。

Performance

⚡ ARM64 硬件加速直通

底层全面集成 NEON SIMD 指令集与 ARMv8 PMULL CRC64 校验，大文件流式打包与解压吞吐量高达 48GB/s。

Virtual VFS

📂 压缩包即虚拟文件夹

支持在内存中对压缩包进行单文件按需流式提取、原地追加与属性检查，无需占用冗余的物理磁盘空间。
