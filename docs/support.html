TTZip 客户支持与使用常见问题

版本：v1.0.0 (Universal Apple Silicon / macOS 14.0+)

常见问题解答 (FAQ)

Q: 如何在压缩包内直接预览文件？

A: 在 TTZip 主界面的分栏浏览（Miller Columns）中选中任意文件，直接按下键盘上的 空格键 (Spacebar)，即可像原生 macOS Finder 一样即时预览图片、代码语法、文本或音频波形。

Q: 如何解决 Windows 压缩包在 Mac 上文件名乱码？

A: TTZip 内置了智能编码识别引擎（uchardet），在打开 ZIP 归档时会自动探测 GB18030、Big5、Shift-JIS、EUC-KR 等编码并无损转换，无需手动切换编码。

Q: 什么是 APFS 零秒写时克隆 (Clonefile)？

A: 当你在 APFS 格式的硬盘或 SSD 上解压同卷文件时，TTZip 会优先调用系统底层的写时复制接口，实现接近 0 秒的瞬间释放，且不会重复占用物理磁盘空间。

Q: 我购买了买断 Key，如何激活？

A: 打开 TTZip -> 点击菜单栏「设置 (Settings)」-> 切换到「授权与分发」标签页 -> 粘贴您的 TTZIP1-... 授权码并点击激活即可。
