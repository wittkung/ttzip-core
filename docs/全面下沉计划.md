> **审计范围**：373 个 Swift 源码与测试文件（已排除 `Vendor/` 与 `.build/`）  
> **核心原则**：算力/安全/CLI 坚决下沉 Rust；展示层/macOS 系统能力坚决保持 Swift 原生。

### 核心判定准则
1. **强烈建议下沉 Rust（算力与安全核心）**：
   - **二进制流解析与反序列化**（ZIP Extra Field / Magic Headers / Tar / 7z 结构）：Rust `nom`/`binrw` 具备极高解析吞吐与 Fuzzing 安全性。
   - **CPU/SIMD 密集型计算**（CRC64、Hardware PMULL、Reed-Solomon FEC 纠错、密码破解、字符集统计探测）：零开销内联与向量化。
   - **虚文件系统与内存页池**（VFS LZ4 缓存池、VirtualMultiBlockArena、MemoryPagePool）：消除 Swift ARC 引用计数争用与内存碎片。
   - **流式多卷与原地编辑**（MultiVolumeStreamSink、InPlaceEdit）：无 GC 停顿与确定性 RAII 资源回收（`Drop`）。
2. **建议下沉 Rust（CLI 与独立工具）**：
   - 将 CLI 命令行重构为基于 Rust `clap` + `ratatui` 的原生工具，消除 Swift 运行时启动开销与动态库依赖，便于交叉编译与跨平台发布。
3. **保持 Swift 原生（禁止下沉）**：
   - 依赖 Apple 闭源系统框架（`AppKit`、`SwiftUI`、`QuickLookUI`、`AVKit`、`LocalAuthentication`、`Sparkle`、`AppleArchive`）。
   - 视图状态机（`@Observable` / `@Published`）与应用生命周期。
