Open Source Stewardship & Giving Back

开源生态回馈与贡献

TTZip 站在巨人的肩膀上成长，我们积极将 Apple Silicon 硬件加速成果回馈至全球开源基础库。

向 libarchive/libarchive 官方上游贡献的生产级成果：

作为全球主流操作系统（macOS/BSD/Linux）的归档核心基石，TTZip 团队已向 libarchive 官方提交多项架构级重构与硬件指令集优化补丁：

  • ✅ ARMv8 ACLE 硬件加速 CRC32 (PR #3391 — 已合入 Master)

    统一全库 CRC32 API 架构，引入 ARMv8 单周期硬件指令加速，支持 GNU Autotools 与 CMake 双构建系统及三层自愈降级。

  • 🔄 7-Zip AES-256-CBC 流式解密流水线 (PR #3388)

    原子 Commit 序列整合加密解压管道，引入 volatile 指针密码安全擦除与严格流式错误回溯。

  • 💡 POSIX 磁盘空间预分配启发式 (PR #3393)

    实测 +39% ~ +70% 吞吐提升，基于 F_PREALLOCATE 与 posix_fallocate 实现零配置透明加速。
