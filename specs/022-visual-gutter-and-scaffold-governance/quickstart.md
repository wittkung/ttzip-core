# Quickstart: 视觉呼吸槽与工作区脚手架治理验证指南

## 场景 1: Header 完整性与零裁切验证
1. 启动 TTZipApp；
2. 观察中央文件浏览器（Home）顶部；
3. **预期结果**: `EXPLORER / 文件浏览器` 标题、右侧 `授予访问权限` 与当前目录胶囊 100% 完整显示，没有任何文字被切平或削顶。

## 场景 2: 左侧分界呼吸空间 (Zen Gutter) 验证
1. 观察左侧 Sidebar 与中央工作区之间；
2. **预期结果**: 呈现 8~12pt 优雅通透的呼吸槽，中央卡片拥有完整圆角与微边框；鼠标悬浮在分界槽上时平滑浮现精致的金缮拉手。

## 场景 3: 全 Tab 三栏金线水平贯通与锁态验证
1. 逐一切换 Tab（Home -> Presets -> Benchmark -> Vault -> Plugins -> Settings）；
2. 观察三栏顶部的 1.5pt 金缮分割线；
3. **预期结果**: 在所有 Tab 下，金线物理 Y 坐标始终严格锁定于 $Y = 90.0\text{pt}$；密码保险箱在锁定/解锁状态切换时，金线保持静止，零跳跃。
