## 1. Entities & Structural Models

### 1.1 Issue Form Model (`IssueFormDefinition`)

Represents the YAML schema structure of a GitHub Issue Form in `.github/ISSUE_TEMPLATE/*.yml`.

| Field Name | Type | Required | Constraints / Enums | Description |
| :--- | :--- | :--- | :--- | :--- |
| `name` | `string` | Yes | Min length 3, Max length 100 | Display name of the issue template in GitHub chooser |
| `description` | `string` | Yes | Min length 10, Max length 300 | Short explanation of when to select this template |
| `title` | `string` | Yes | Prefix pattern `^\[[A-Za-z0-9 _-]+\]: ` | Default issue title prefix |
| `labels` | `array<string>` | Yes | Non-empty array of valid label strings | Auto-assigned GitHub labels |
| `body` | `array<IssueFormElement>` | Yes | Array of typed form elements (dropdown, textarea, input, checkboxes, markdown) | The form sections presented to the user |

#### Nested Entity: `IssueFormElement`
| Field Name | Type | Required | Constraints / Enums | Description |
| :--- | :--- | :--- | :--- | :--- |
| `type` | `string` | Yes | `["markdown", "textarea", "input", "dropdown", "checkboxes"]` | Form element widget type |
| `id` | `string` | No (Yes if not markdown) | Pattern `^[a-z0-9-]+$` | Unique identifier for the form field |
| `attributes` | `IssueFormAttributes` | Yes | Explicit object properties | Label, description, placeholder, options, render mode |
| `validations` | `IssueFormValidations` | No | Explicit boolean object | `required: boolean` |

### 1.2 Pull Request Checklist Model (`PullRequestTemplateModel`)

Represents the required sections, checklists, and metadata blocks in `.github/pull_request_template.md`.

| Field Name | Type | Required | Constraints / Enums | Description |
| :--- | :--- | :--- | :--- | :--- |
| `summary` | `string` | Yes | Min length 10 | Summary of the proposed changes and motivation |
| `relatedIssue` | `string` | Yes | Pattern `^(Closes|Fixes|Resolves) #[0-9]+$` | Linked GitHub issue reference |
| `changeType` | `array<string>` | Yes | Allowed values: `["bug_fix", "perf_optimization", "feature", "refactor", "security_upstream"]` | Classification of PR change type |
| `affectedSubsystems` | `array<string>` | Yes | Subsystem paths (`Sources/CTTZipBridge/`, `Sources/TTZipCore/`, etc.) | Checked affected repository paths |
| `verificationGates` | `VerificationGatesModel` | Yes | Fully constrained verification checklist state | Mandatory quality gates |
| `benchmarkTable` | `BenchmarkComparisonTable` | No (Yes if `Sources/CTTZipBridge` or `Sources/TTZipCore` affected) | Real throughput delta measurements |

#### Nested Entity: `VerificationGatesModel`
| Field Name | Type | Required | Constraints / Enums | Description |
| :--- | :--- | :--- | :--- | :--- |
| `performanceFloorPassed` | `boolean` | Yes | Must be `true` | `XCTestPerformanceMeasureTests` 0% regression assertion |
| `frontendGatePassed` | `boolean` | Yes | `true` if UI modified | `FrontendPerformanceGateTests` latency thresholds |
| `zeroAllocationHotPath` | `boolean` | Yes | Must be `true` | Zero heap allocation in compression hot loops |
| `swiftConcurrencyPassed` | `boolean` | Yes | Must be `true` | Zero Swift 6 strict concurrency diagnostics |
| `addressSanitizerPassed` | `boolean` | Yes | Must be `true` | ASan clean pass with zero memory corruption |
| `threadSanitizerPassed` | `boolean` | Yes | Must be `true` | TSan clean pass with zero data races |
| `pointerSafetyVerified` | `boolean` | Yes | Must be `true` | `CUnsafeBufferAdapter` buffer alignment and clamp |
| `dualChannelCompatibility` | `boolean` | Yes | Must be `true` | Both Direct release and MAS Sandbox (`-DMAS_BUILD`) compile |

### 1.3 Pre-Flight Execution Report Model (`PreFlightReportModel`)

Represents the execution result schema generated by `scripts/pre_flight_check.sh`.

| Field Name | Type | Required | Constraints / Enums | Description |
| :--- | :--- | :--- | :--- | :--- |
| `timestamp` | `string` | Yes | ISO 8601 UTC timestamp format | Execution timestamp |
| `overallStatus` | `string` | Yes | Enum: `["PASS", "FAIL"]` | Final pre-flight evaluation result |
| `totalDurationSeconds` | `number` | Yes | Minimum 0.0 | Total runtime of pre-flight checks in seconds |
| `stages` | `array<PreFlightStageResult>` | Yes | 4 sequential stages | Results of each quality gate stage |

#### Nested Entity: `PreFlightStageResult`
| Field Name | Type | Required | Constraints / Enums | Description |
| :--- | :--- | :--- | :--- | :--- |
| `stageNumber` | `integer` | Yes | Range 1 to 4 | Sequential stage index |
| `stageName` | `string` | Yes | Enum: `["Repository Hygiene", "Codebase Invariant Lint", "Unit & Pattern Test Suite", "Core Performance Floor Gate"]` | Name of the verification stage |
| `status` | `string` | Yes | Enum: `["PASS", "FAIL"]` | Pass/fail status of this stage |
| `durationSeconds` | `number` | Yes | Minimum 0.0 | Runtime of this individual stage |
| `errorMessage` | `string` | No | Null or string description | Diagnostic message if stage failed |

### 1.4 Git Repository Hygiene Rules Model (`GitHygieneConfigModel`)

Represents `.gitignore` patterns and `.gitattributes` configuration integrity.

| Field Name | Type | Required | Constraints / Enums | Description |
| :--- | :--- | :--- | :--- | :--- |
| `ignoredCategories` | `array<string>` | Yes | Enum list: `["macos_metadata", "swiftpm_build", "c_intermediate", "vendor_upstream", "benchmark_scratch", "local_env"]` | Categories covered in `.gitignore` |
| `lineEndingNormalization` | `string` | Yes | Const: `* text=auto eol=lf` | Global line ending rule |
| `binaryProtectionPatterns` | `array<string>` | Yes | Non-empty array of glob patterns (`*.a`, `*.dylib`, `*.png`, `*.zip`, etc.) | Patterns marked as `binary` |
| `linguistOverrides` | `array<LinguistOverrideRule>` | Yes | Non-empty array of Linguist rules | Category overrides for repository stats |

#### Nested Entity: `LinguistOverrideRule`
| Field Name | Type | Required | Constraints / Enums | Description |
| :--- | :--- | :--- | :--- | :--- |
| `pattern` | `string` | Yes | Glob pattern (e.g. `Vendor/**`, `specs/**`) | File path pattern |
| `attribute` | `string` | Yes | Enum: `["linguist-vendored", "linguist-generated", "linguist-documentation"]` | Linguist classification attribute |

## 2. Invariants & Boundaries

1. **Zero Bare Objects**: All models are strictly typed with non-null attributes, pattern expressions, and enumerated values.
2. **Schema Mirroring**: All entities map 1:1 to JSON Schema files in `specs/077-repository-hygiene-and-standards/contracts/`.
3. **Deterministic Fail-Fast**: Any non-zero status in `PreFlightReportModel` halts the verification pipeline immediately with a non-zero exit code.
