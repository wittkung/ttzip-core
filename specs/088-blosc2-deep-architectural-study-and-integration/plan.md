## Summary

Deep architectural study and native integration of four core C-Blosc2 system pillars into TTZip:
1. **SIMD BitShuffle & 128-Byte Prefix-Sum ByteDelta**: Vector bit-matrix transposition (64-bit delta-swap on `uint64x2_t`) and 8-way unrolled Kogge-Stone prefix sums on Apple Silicon NEON.
2. **Special-Value Uniform Block Bypass**: Branchless SWAR/NEON uniform block scanner detecting `SPECIAL_ZERO`, `SPECIAL_NAN`, and constant patterns with $O(1)$ disk payload and $> 80\text{ GB/s}$ `dc zva` memory-bus saturated fill.
3. **Two-Tier Cache-Aware Partitioning (128KB L1D) & Shared Frame Dictionary**: Super-Chunk container geometry with frame-level pre-trained Zstd dictionary sharing.
4. **Heuristic Small-Block Auto-Tuner (BTune-Inspired)**: 16KB micro-sampling engine using Shannon entropy and stride autocorrelation for Pareto-optimal filter/codec selection.

## Technical Context

**Language/Version**: Swift 6.0 (`swift-tools-version: 6.0`) + C11 / POSIX APIs / ARM NEON Intrinsics (`<arm_neon.h>`).

**Primary Dependencies**: In-process C static libraries (`Vendor/libzstd.a`, `Vendor/libdeflate.a`, `Vendor/liblz4.a`, `Vendor/liblzma.a`).

**Storage**: Memory-mapped page buffer pools, contiguous frames (`.b2frame`), and standard archives (`.zip`, `.7z`, `.tar.zst`).

**Testing**: XCTest / Swift Testing (`swift test`, `swift test --filter Blosc2*`).

**Target Platform**: macOS 14.0+ (Sonoma, Sequoia) on Apple Silicon (M1/M2/M3/M4) and Intel x86_64.

**Project Type**: High-performance systems library, C-bridge engine, and macOS native application.

**Performance Goals**:
- BitShuffle NEON: $\ge 4,000\text{ MB/s}$ (single core).
- ByteDelta NEON: $\ge 8,000\text{ MB/s}$ encode / $\ge 14,000\text{ MB/s}$ decode.
- Special Zero Fill: $\ge 25,000\text{ MB/s}$ (up to $> 80\text{ GB/s}$ via `dc zva`).
- Micro-Probe Overhead: $\le 0.15\%$ on streams $> 1\text{ MB}$.

**Constraints**: Zero dynamic heap allocations on hot paths; 64KB stack-buffered zero-copy execution; bit-for-bit lossless data recovery.

**Scale/Scope**: Arbitrary stream and container sizes ($1\text{ KB}$ to $> 100\text{ GB}$), handling $> 500,000$ files in batch pipelines.

## Phase 0: Outline & Research

- R001 [SUBAGENT:research] 《SIMD BitShuffle & Vector Bit-Matrix Transposition》：研究 C-Blosc2 BitShuffle 算法与 ARM NEON 64 位三级分治 delta-swap 向量化转置实现。
- R002 [SUBAGENT:research] 《SIMD ByteDelta Differencing & Prefix-Sum Vector Reconstruction》：研究 C-Blosc2 ByteDelta 算法与 Apple Silicon 128 字节对齐 Kogge-Stone 并行前缀和向量重构。
- R003 [SUBAGENT:research] 《Special-Value Uniform Block Bypass》：研究 C-Blosc2 `BLOSC2_SPECIAL_ZERO` / `SPECIAL_VALUE` 无分支向量扫描与 Darwin `dc zva` / `memset_pattern8` 内存总线饱和快速填充。
- R004 [SUBAGENT:research] 《Two-Tier Cache-Aware Partitioning & Shared Frame Dictionary》：研究 Super-Chunk $\rightarrow$ Chunk $\rightarrow$ Block 两级缓存对齐划分（128KB L1D）与 Frame 级 Zstd 共享字典预训练架构。
- R005 [SUBAGENT:research] 《Small-Block Heuristic Auto-Tuning (BTune Optimization)》：研究 16KB 微采样香农熵与多步长自相关快速探测，实现 Pareto 最优前置过滤器与编解码器自适应决策。
