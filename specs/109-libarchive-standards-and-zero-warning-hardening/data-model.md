# Phase 1 Data Model: Libarchive Standards & Zero-Warning Codebase Hardening

## 1. Entity: `LintStandardsReport`

Represents the automated audit report generated by `scripts/lint_codebase_standards.sh`.

| Field Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `status` | String (enum: `PASS`, `FAIL`) | Yes | Overall verification result |
| `spdxHeadersVerified` | Integer | Yes | Count of TTZip-authored source files with valid SPDX license header |
| `spdxMissingCount` | Integer | Yes | Count of files missing valid SPDX header |
| `nonAsciiViolations` | Array of String | Yes | List of `file:line` occurrences with non-ASCII characters in C bridge |
| `compilerWarningsCount` | Integer | Yes | Total compiler warnings captured under `-warnings-as-errors` |
| `timestamp` | String (ISO-8601) | Yes | Execution timestamp |

---

## 2. Entity: `TestExecutionReport`

Represents the structured in-process test execution metrics collected by `TTZipTestObserver`.

| Field Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `totalSuites` | Integer | Yes | Total number of test suites executed |
| `suitesPassed` | Integer | Yes | Count of test suites with zero failures |
| `suitesFailed` | Integer | Yes | Count of test suites with one or more failures |
| `totalTests` | Integer | Yes | Total test case count |
| `testsPassed` | Integer | Yes | Count of passed test cases |
| `testsSkipped` | Integer | Yes | Count of skipped benchmark test cases |
| `testsFailed` | Integer | Yes | Count of failed test cases |
| `totalDurationSeconds` | Float | Yes | Wall-clock execution time in seconds |
| `failures` | Array of Object | Yes | Detailed failure diagnostic list |
| `failures[].file` | String | Yes | Source file path of failure |
| `failures[].line` | Integer | Yes | Line number of assertion failure |
| `failures[].message` | String | Yes | Exact assertion failure message |
| `failures[].testMethod` | String | Yes | Name of the failing test method |

---

## 3. Entity: `ZipProfileDefinition`

Represents one of the 8 golden compression profiles (`ZipCompressionProfile`).

| Field Name | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `tier` | Integer (0..7) | Yes | Golden tier index |
| `name` | String | Yes | Profile identifier (e.g. `store`, `fast`, `extremePeak`) |
| `deflateLevel` | Integer (0..12) | Yes | Underlying libdeflate or Zopfli level |
| `zopfliIterations` | Integer (0..15) | Yes | Number of Zopfli iterative passes |
| `targetThroughputFloorMBs` | Float | Yes | Hard throughput floor in MB/s |
