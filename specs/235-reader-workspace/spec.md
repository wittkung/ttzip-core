# EPUB 阅读工作区（用户 Round 5）

先定义行为，再实施；现有 WIP 保留。

- 分页模式严格一次一页，禁止滚轮/触控板造成半页与惯性滚动；滚动模式为显式选项。章节末尾进入下章，反向进入上章末页。
- 中文/英文字体独立，出版物结构、插图、标题与表格语义保留；用户字号/字体覆盖仅作用文本，深色主题不得消隐正文或反色插图。
- 进度采用稳定书本 identity + spine chapter + DOM block/character anchor + ratio，重排后重新测量，不持久化临时解压 URL。
- Rust 负责偏好、锚点验证、注释 CRUD、JSON/Markdown 导出和原子持久化；WebKit 负责 DOM selection 与排版测量，SwiftUI 负责交互与系统字典/网页/保存面板。
- 选区划线与笔记可列出、定位、删除、导出。外部网页仅用户显式触发；出版物脚本不获宿主文件写入能力。
- 独立阅读窗口复用宿主统一窗口机制，不在 EPUB 创建另一套窗口管理器。
